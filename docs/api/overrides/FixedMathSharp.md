FixedMathSharp provides deterministic Q32.32 scalars, vectors, rotations,
matrices, transforms, curves, ranges, and shared geometry relations for .NET.

The core package is engine-agnostic. Unity projects should use the maintained
[FixedMathSharp-Unity packages](https://github.com/mrdav30/FixedMathSharp-Unity)
for Unity Package Manager installation and engine-specific interop.
